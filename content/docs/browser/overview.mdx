每个 Orca 工作树都有自己的浏览器。它是一个真正的 Chromium 窗口 — 地址栏、历史记录、devtools — 嵌入在一个面板中。标签限定在该工作树内，这样你正在构建的应用不会干扰你其他的工作。

## 控件

- 带历史记录和模糊 URL 补全的地址栏。非 URL 文本会使用你的 [默认搜索引擎](/docs/settings) 搜索 — 与 [新标签 omnibox](/docs/model/quick-open#new-tab-omnibox) 使用的是同一个引擎。在 **+** 字段中用 `?` 前缀查询可强制搜索。
- 后退 / 前进 / 重新加载 / 停止。悬停重新加载控件显示普通重载的快捷键；右键（或长按）显示 **重载** 和 **硬重载** 及其快捷键 — 硬重载会绕过缓存，适合在迭代本地前端资源时使用。
- `Cmd-F` — 在页面中查找。
- `Cmd-T` — 新标签，限定于此工作树。
- `Cmd-Shift-T` — 重新打开最后关闭的标签。
- 使用 `target=_blank` 的页面链接和普通的未命名弹窗在可用时会在可见浏览器面板中的新 Orca 标签中打开，使用发起标签的浏览器 profile。命名的或 OAuth 风格的弹窗仍可能在单独窗口中打开。

## 工作树范围

标签按工作树过滤。切换工作树会恢复该工作树的浏览器标签和滚动位置。

## 远程工作空间

对于配对的 [远程 Orca 服务器](/docs/remote-servers) 上的工作空间，新浏览器页面默认在本桌面端渲染，而 HTTP(S)、WebSocket、DNS 和环回流量仍然通过远程主机。输入、选择和弹窗保持本设备原生，不改变页面的网络身份。浏览器工具栏中的主机指示器显示流量去向。

在 [设置 → 浏览器 → 远程服务器工作空间](/docs/settings) 下，选择 **本设备** 或 **服务器（流式传输）**。该选择仅应用于新页面；不会移动已经打开的页面。如果本地渲染的远程页面无法启动，**在服务器上重新打开** 会在其最后一个地址打开一个新的服务器托管页面（登录或表单状态可能不同）。

对于 SSH 工作空间，**通过 SSH 工作空间主机浏览** 控制浏览器流量和 DNS 是通过工作空间的 SSH 主机还是本设备。客户端托管的远程页面下载保持在远程工作空间主机上，上传会在页面接收前暂存在那里。

## 链接路由

在 [设置 → 浏览器 → 链接路由](/docs/settings) 下，选择终端、markdown 和编辑器中的 http(s) 链接是在 Orca 的每个工作树浏览器中打开，还是在系统浏览器中打开。

在 Orca 中打开的链接首先会在同一工作空间、执行主机和浏览器 profile 中复用完全相同目标的已有页面。否则会在已经显示浏览器的面板中打开新标签。当多个浏览器面板可见时，聚焦的那个优先，然后是最近使用的。隐藏在其他标签后的浏览器标签不会吸引新页面。没有浏览器可见时，会在源面板旁边打开新分屏，保持其内容可见。显式的 **在新标签中打开** 操作使用请求的面板替代。

嵌套的 **按住 Shift…** 开关用平台修饰键（macOS 上 `⇧⌘-点击`，Windows / Linux 上 `Shift+Ctrl+点击`）为单次点击反转默认行为：

- 当链接在 **Orca** 中打开时，修饰键会将单个链接发送到系统浏览器。
- 当链接在 **系统浏览器** 中打开时，打开此开关后修饰键会在 Orca 内置浏览器中打开单个链接（普通点击仍然是系统）。

已验证能力的配对运行时可以为其终端链接提供相同的 Orca/系统浏览器选择；来自较旧运行时的链接只能使用系统浏览器。主机路由的 SSH 链接遵循链接路由。当主机的 SSH 浏览设置为 **本设备** 时，它们在 Orca 标签中打开，且仅从本设备浏览（当链接在 Orca 中打开时）；否则它们只能使用系统浏览器。参见 [终端 → 链接操作](/docs/terminal#link-actions)。

## 下载

浏览器下载在活动或最近完成时会出现在工具栏下方的架子中，带有取消进行中下载、打开已完成文件、在文件夹中显示或关闭该行的操作。

## 作为 artifact 分享

在工作树浏览器中打开的本地 HTML 文件可以在工具栏中使用 **作为 artifact 分享**，通过你已登录的 Orca 账户创建公开查看链接（与 Markdown 相同的发布门和管理界面）。相对 HTML 资源不会上传 — 请分享自包含文件或使用绝对资源 URL。参见 [设置 → Artifacts](/docs/settings#artifacts) 和 [CLI 参考 → Artifacts](/docs/cli/reference#artifacts)。

## 视口尺寸模拟

在浏览器标签上设置自定义视口尺寸，在不调整整个面板大小的情况下测试响应式布局。Orca 底层使用 Chrome DevTools Protocol 设备模拟，因此页面可以在 `window.innerWidth` 和媒体查询中看到模拟的尺寸。

## 自动化

浏览器也可以由代理通过 [Orca CLI](/docs/cli/overview) 来脚本化 — `orca snapshot`、`orca click`、`orca fill` 等。和你交互的是同一个浏览器，同样的标签。
