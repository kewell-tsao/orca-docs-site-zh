设计模式将 Orca 浏览器变成一个指针到代码的工具。开启它，点击渲染页面上的任何 UI 元素，该元素会作为富上下文落入代理聊天 — 包含其 DOM、计算样式和截图。

## 开启它

点击浏览器工具栏中的 **设计模式** 开关。你的光标变成一个拾取器；悬停时会高亮它下方的元素。

## 落入聊天

点击一个元素。Orca 捕获：

- 该元素的 HTML（outer 和一个小的邻近区域）。
- 其计算后的 CSS — 颜色、字体、间距。
- 该元素的裁剪截图。
- 如果有开发模式的 source map，还包含源文件/行号。

所有这些会作为一个附件一起发送到活动代理终端，然后你输入想要修改的内容。

## 使用结果

代理编辑源码，Orca 热重载，你再次点击验证。这个循环最紧凑的实现就是英雄级食谱 [用设计模式修复 UI bug](/docs/recipes/design-mode-fix)。
