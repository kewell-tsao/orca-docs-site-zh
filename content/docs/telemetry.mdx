本页描述我们在打包的 Orca 构建中收集的匿名产品使用遥测、我们从不收集什么，以及如何退出。

## 概要

- **匿名。** 事件由随机 ID 键入，存储在您机器本地。不收集账户、邮箱、IP 地址或用户名。
- **无内容。** 我们从不传输文件内容、提示、代理输出、终端输出、仓库名称、分支名称、URL、路径或提交消息。
- **始终关闭当：** 设置了 `DO_NOT_TRACK=1` 或 `ORCA_TELEMETRY_DISABLED=1`。

## 我们收集什么

在每个事件旁边，我们包含基本的构建和平台信息：Orca 版本、您的操作系统（例如 `darwin` / `win32` / `linux`）、CPU 架构、粗略 OS 发布字符串、发布渠道（`stable` 或 `rc`），以及上面描述的匿名本地 ID。无主机名、无用户名、无 IP。

我们观察的行为类别：

- **生命周期** —— 应用何时打开，包括代理仪表板当前是否启用。用于估算每日、每周和每月活跃用户及功能采用率，包括在测量开始前就启用了仪表板的用户。
- **代理仪表板** —— 看板何时打开以及它在 UTC 日期内是否可见，标记为窗口内或弹出面板。可见使用观察仅限于每个表面每天一次，跨应用重启，因此跨天保持可见的看板每天都被计数。隐藏或最小化的窗口暂停这些观察。这测量可见使用天数，而非花费的时间或人类注意力；不包含卡片或代理内容。
- **仓库和工作空间** —— 您何时添加仓库或创建工作空间。我们记录 _如何_ 做到的（例如文件夹选择器 vs 克隆 URL；命令面板 vs 拖放），从不记录仓库名称、URL、路径、分支名称或任何自由文本。对于工作空间创建，我们还记录花了多长时间以及时间如何拆分到其步骤中，Orca 预先准备的检出是否被重用（如果是，它需要什么重置、准备它的是什么、准备花了多长时间以及等待了多久未使用；如果不是，固定的原因代码），失败的创建停在了哪个步骤，加上粗略上下文：它来自 Orca 窗口还是 CLI、手机或代理接口，Git 是本地运行、在 WSL 中还是通过 SSH，分桶的工作树数量、仓库跟踪的文件的分桶计数、还有多少其他创建和准备好的检出作业正在运行，以及仓库是否有检出后钩子（从不记录其内容）。
- **代理** —— 您使用哪些代理及其令牌计数。从不记录提示或代理输出。
- **激活和活跃天数** —— 每个安装配置文件一次，观察到向代理发送了第一个提示或消息（哪个代理类型和哪个表面：Orca 发送、聊天、手机，或代理钩子看到的提示），每个 UTC 天最多一次，您采取了显式操作（例如启动代理、发送消息、创建工作空间或在终端中输入 —— 仅哪种操作先来）。包括此记录首次记录时配置文件是否为新的。从不记录提示、消息或任何键入内容。
- **代理错误** —— 粗略错误类别和涉及的代理类型。我们从不看到原始错误消息或堆栈跟踪；每个事件详情留在您机器上的本地诊断跟踪文件中，仅在您显式共享诊断包时到达 Orca。
- **设置** —— 当您切换一小组白名单的功能标志或 UX 偏好时。我们记录哪个偏好更改了以及它是布尔值还是枚举，从不记录任何自由文本设置的原始值。
- **标签操作** —— 对匿名安装的稳定 10% 样本，应用会话中第一次选择"向左关闭标签"或"向右关闭标签"，所有窗口每个会话限制两个事件。对于每个方向的首次请求，我们记录选定标签的类型、它在工作空间还是浮动面板、有多少未固定标签符合关闭条件以及采样率。应用打开事件包含样本成员身份，因此我们可以测量每个命令的采样会话份额。重复请求不被记录，因此这些事件不测量点击频率、按标签类型或面板的总使用量，或总关闭的标签数。这计数请求，包括当您取消保存提示时；从不记录标签标题、文件路径或工作空间标识符。
- **聊天 UI 公告** —— 是否显示了公告、其变体和推出组，以衡量有效性。
- **隐私控件** —— 当您加入或退出遥测时，因此我们可以从聚合数据中判断我们的同意 UI 是否工作。
- **SSH 远程运行时** —— 每个 SSH 主机和每个应用会话的结果一次，Orca 使用哪个运行时在该主机上运行以及原因，或其运行时检查无法确认或失败：粗略主机事实（操作系统、CPU 架构、C 库系列和 glibc 次版本，以及 Orca 在其上运行时主机的 Node.js 主版本）、任何拒绝的类别（包括 Windows 上安全软件阻止运行时）、是否上传了运行时，以及粗略持续时间桶。从不记录主机名、用户名、路径或原始错误文本。
- **插件** —— 当您从 Orca 官方或社区目录安装或更新插件时。我们记录插件的公共名称 (`publisher.id`)、其版本、来自这两个目录的哪一个、是否首次安装、更新或重新安装，以及您是从目录、安装链接还是通过自动更新开始的。这些事件为插件目录上的公共安装计数提供动力，因此仅统计共享使用数据的用户。您自己添加的目录、Git URL 或本地/开发文件夹的插件从不报告。

字段包括固定枚举值、版本字符串、数字计数和修订以及随机本地 ID。会话 ID 允许同一会话的重复令牌摘要被关联；它们是伪匿名的。插件名称是其目录列出的公共标识符。任何 UI 输入的自由文本从不离开您的机器。

## 交付和准确性

远程结构化聊天代理启动事件在连接时尽力而为地传递到发起的桌面。重连后事件不会被保留或重放。这可能低估远程使用量；这些事件不提供代理启动的完整记录。

## 我们从不发送什么

- 无文件路径、仓库名称、分支名称、URL、提交消息或当前工作目录。
- 无代理提示、响应或终端内容。
- 无原始错误消息或堆栈帧。每个事件错误上下文留在您机器上的本地诊断跟踪文件中，仅在您显式共享诊断包时到达我们。
- 无用户账户信息（Orca 没有账户系统）。
- 无 IP 地址，也无精确的 geoip；国家是从请求派生的唯一地理信号。
- 无与您的匿名 ID 绑定的供应商侧用户档案。

## 如何退出

您可以通过三种方式禁用遥测。其中任何一种都足够；它们可以组合。

1. **在应用中。** 设置 → 隐私 → 关闭"共享匿名使用数据"。更改即时生效并持久化。

  src="/docs/privacy-toggle.png"

2. **`DO_NOT_TRACK=1`** —— 社区标准环境变量。为此启动禁用传输。取消设置后下次启动恢复您存储的偏好。
3. **`ORCA_TELEMETRY_DISABLED=1`** —— Orca 特定的开关，与 `DO_NOT_TRACK` 语义相同。

## 数据去向

- **提供商：** PostHog Cloud，**美国** 区域。
- **保留：** PostHog Cloud 按其定价页面的计划级默认值。我们不设置自定义保留窗口。
- **访问：** 项目成员资格限于少量 Orca 维护者。
