title: 移动伴侣

---

import { Callout } from '@/components/docs/prose'

Orca 移动伴侣是一个 iOS/Android 应用，配对到您的桌面 Orca，让您监控和控制正在运行的代理 —— 代理状态、最近的终端滚动缓冲区、终端输入、源代码控制和代理账户。配对建立对选定主机的持久访问；桌面仍是事实来源。

<Callout title="Beta">
  移动伴侣处于 beta。iOS 从 [App
  Store](https://apps.apple.com/us/app/orca-ide/id6766130217) 安装，Android 从 [Google
  Play](https://play.google.com/store/apps/details?id=dev.orca.app) 安装。如果您的设备上
  Google Play 不可用，安装 [当前 APK](https://orca.dev/download/android)。
</Callout>

## 您可以从移动设备做什么

- 查看每个工作树、其代理和当前状态（正在工作 / 已完成 / 等待输入）。移动在单个视图中列出您连接到的每个主机（本地桌面和远程 Orca 服务器）的工作树，因此切换它们不需要更换设备。
- 从移动浏览工作空间的完整文件树 —— 包括深层嵌套路径 —— 因此您可以跳入任何文件而无需等待桌面。
- 在 **聊天 UI**（聊天风格转录）或原始终端中打开支持的代理会话。在设置 → 聊天 UI 下设置设备默认值，或长按会话标签仅为该标签切换。
- 水合最近的终端滚动缓冲区，因此您可以读取代理做了什么或问了什么。聊天风格视图中的 Markdown 在消息包含它们时可以渲染 **Mermaid** 图。
- 从移动终端视图选择、复制和粘贴文本 —— 长按选择，分享面板粘贴回回复中。
- 使用终端附件行处理在手机键盘上很麻烦的按键，包括 `Tab` 和 `Shift+Tab`，或当每个键入字符应直接进入活动终端时切换到 **实时**。
- 当代理等待输入时发送简短回复（`continue`、`yes`、自由文本），附加照片或文件，或点击麦克风口述回复。在 **实时** 模式下，口述文本插入活动终端而不替您按 Return。在聊天 UI 中，附加的图像在您的消息上显示为缩略图，可以带或不带文本发送。
- 从会话标签条运行 **快速命令** —— 与桌面列表同步的已保存终端命令或代理提示。
- 长按会话标签进行批量关闭操作（**关闭其他标签**、**向左关闭标签**、**向右关闭标签**）。未保存的 Markdown 标签和固定标签被跳过。
- 当您需要从手机检查响应式页面时，在 **Web** 或 **移动** 视图中打开浏览器会话。
- 打开工作树的源代码控制以评审更改的文件、暂存或取消暂存，从手机提交。
- 切换活动代理账户，随时查看使用量 / 速率限制状态。当 Codex 获得重置积分时，从账户页面使用一个。
- 使用与桌面相同的智能源模式从移动创建工作空间：智能、GitHub、Linear、GitLab、分支和名称。在 **多个连接的桌面** 时，**新工作空间** 询问应先在哪台主机上创建（一个连接的主机跳过选择器）。
- 打开主机卡片的 **⋯** 菜单进行 **编辑**、**连接**、**移除** 和相关操作（长按仍可用作快捷方式）。
- 无需重新配对即可编辑已保存主机的显示名称或连接地址（例如当桌面在家 LAN 和 Tailscale 之间移动时）。
- 当代理完成时获取推送通知，镜像 [桌面通知](/docs/notifications)。

移动应用有意不是完整编辑器 —— 它是您已在运行的桌面的远程控制器。

## 配对

1. 在桌面上，从账户 / 状态菜单打开 Orca 的配对流程。Orca 显示配对代码。将其视为机密，仅与您要授权的设备共享。
1. 在移动设备上，打开 Orca 伴侣应用并选择 **配对**，然后粘贴代码。（您也可以从桌面直接跟随深层链接进入移动配对屏幕。）
1. 可用时优先使用 **Orca Relay** 进行配对 —— 仅 Relay 需要登录。本地网络地址选择器在 Relay 上可选（当您想要 LAN 快速路径时展开）；LAN 配对仍需要地址。
1. 配对交换为该手机建立设备令牌；在您选择的路径上保持桌面可达。

关闭桌面应用会断开直接/LAN 会话直到您重新打开。Relay 支持的配对遵循桌面 Relay 连接 —— 如果主机离线请重新打开桌面。

当前桌面 UI 配对提供的移动在 10 分钟后过期，运行时客户端在一小时后过期。已配对设备的授权在提供过期后持续存在，直到被撤销。无头提供和旧版本可能有不同生命周期；不要假设每个代码都是单次使用或自动过期。如果未使用的代码可能已暴露，重新生成它。

### 访问和信任

已配对的手机可以读取工作空间文件、发送终端输入并控制已配对主机上的代理以及通过它提供的已连接远程运行时。配对不是企业只读或每个仓库的沙箱。使用访问权限适用于手机用户的主机账户，并用其 OS 锁和您组织的设备控制保护手机。

已配对的桌面可以独立于移动商店更新传递移动 web UI 和 JavaScript。这些资产通过经过认证的配对连接传输，并对照清单哈希检查。桌面是手机信任边界的一部分；这些检查不为每个下载的 UI 包提供单独的发布者签名或商店评审。

### 撤销手机或响应设备丢失

1. 在每个已配对的桌面上，打开移动设置并从已配对设备列表中移除手机。确认操作成功；在手机上移除已保存的主机不是主机端撤销的替代品。
1. 主机端撤销移除设备授权并关闭该主机上的活动连接。Relay 凭据清理被持久排队，需要连接到服务才能完成。同步成功时远程运行时接收更新的委托设备授权。如果主机离线或清理未完成，限制其网络访问直到确认撤销；无法保证跨离线主机的即时撤销。
1. 对于丢失的手机，使用您的设备管理工具锁定或擦除它，并审查任何单独授予的主机或提供商访问权限。撤销 Orca 访问不会远程擦除手机上已保存的文件、截图、剪贴板内容或其他数据。
1. 如果您怀疑配对代码被共享，在主机上重新生成它并审查已配对设备，然后再配对替换手机。

## 聊天 UI

对于聊天能力的代理（Claude、Codex 和 Orca 识别的其他），移动可以在 **聊天 UI** 而非原始终端中打开会话 —— 与桌面的 [聊天 UI](/docs/agents/native-chat) 相同概念：可读的转录、编辑器、权限/问题和图片附件。

- **设备默认** —— 首次启动时，移动询问会话应在此手机上如何打开。稍后在 **设置 → 聊天 UI → 在聊天 UI 中打开会话** 下更改。默认为终端直到您选择聊天 UI。
- **每个会话** —— 长按会话标签并选择 **切换到聊天视图** 或 **切换到终端视图**。该覆盖坚持该标签，不改变设备默认值。
- **编辑器** —— 键入回复、`@` 提及工作空间文件、从共享目录使用代理感知的 `/` 斜杠命令（Claude vs Codex 设置，带描述）、附加照片或口述。附加的图像显示为可移除的缩略图，随发送一起传递（包括仅图像发送和多图像附件）。
- **模型和会话选项** —— 编辑器显示当前模型和会话选项的胶囊行。点击它选择模型或选项（包括直接 Codex 模型选择），而不进入原始终端。
- **桌面仍拥有代理** —— 聊天 UI 是已配对桌面会话上的视图，不是独立的云代理。

## 快速命令

从工作树会话中，从会话标签条（下一个终端旁边）打开 **快速命令**。命令与桌面列表相同，双向同步。

- **终端命令** —— 在新标签中粘贴或运行 shell 命令（可选不按 Enter，以便您先编辑）。
- **代理提示** —— 用已保存的提示体打开选定的代理。
- 从行的复制控件将命令主体复制到剪贴板（主体为空时禁用）。
- 全局或当前项目作用域命令。从工作表添加、编辑和删除；桌面主机强制执行共享列表上限。

如果已配对的桌面太旧，启动器被禁用，直到您更新桌面。

## 会话标签

长按会话条中的标签进行标签操作，包括 **关闭**、**关闭其他标签**、**向左关闭标签** 和 **向右关闭标签**。批量关闭跳过脏 Markdown 标签（移动上关闭时没有保存提示）和固定标签。对于聊天能力的代理标签，相同的长按工作表可以切换聊天 UI ↔ 终端。

## 账户切换器

移动应用暴露与桌面状态栏相同的账户切换器，包括非活动账户的内联使用量。账户屏幕在提供商报告会话或每周窗口的重置时间戳时显示重置倒计时。在这里切换会切换到已配对的桌面。

当活动 Codex 账户获得 **速率限制重置** 积分时，账户屏幕显示可用数量（以及下一个何时过期）和 **使用重置** 操作。确认后为当前 Codex 目标（主机或 WSL 发行版）消耗一个积分并刷新符合条件的速率限制窗口。与桌面一样，您的计算机追踪该尝试，因此在连接不稳定后重试会显示真实结果且从不消耗第二个积分。结果包括成功、无符合条件的重置、剩余积分，或重置已应用。另见 [使用量 & 速率限制追踪](/docs/agents/usage-tracking)。

## 创建工作空间

从移动主屏幕，打开 **创建工作空间** / **新工作空间** 并选择源模式。**智能** 跨支持的任务提供商和分支搜索；提供商特定模式将创建缩小到 GitHub、Linear、GitLab、分支或普通工作空间名称。选择源后，在已配对的桌面上创建工作空间前使用 **高级** 进行命名和分支控制。如果连接了多个桌面，先选择主机（选择器显示每个端点以便相似名称可区分）。没有连接的桌面时，操作保持禁用。

## 编辑已配对主机

在主机列表上，点击主机卡片的 **⋯** 按钮（或长按卡片）并选择 **编辑主机**。

- **名称** —— 仅在此手机上的显示名称。
- **地址** —— IP、`host:port` 或 `ws://` / `wss://`。缺少端口保持当前端口（或默认为 `6768`）。地址编辑仅更改此手机连接的位置；它们 **不** 重新配对。当同一桌面在不同路径上可达时使用（例如家 LAN vs Tailscale）。

保存地址更改会重新连接到新端点。配对令牌保持不变。

## 移动上的源代码控制

从工作树会话中，点击分支图标打开源代码控制。将它用于小型后续操作：检查分支状态、检查更改的路径、暂存或取消暂存文件，并在暂存集准备好后提交。如果分支已有 GitHub pull request，使用空 PR 状态中的 **链接现有 PR** 附加它而非创建新的。

## 移动上的浏览器视图

移动浏览器面板有 **Web / 移动** 切换。使用 **Web** 查看正常页面，使用 **移动** 向已配对的桌面浏览器请求手机大小的响应式视口。

## 终端设置

移动终端有专门的 **终端设置** 屏幕（设置 → 终端）：

- **文字大小** —— WebView 在适配宽度之上应用的 50%–200% 基线缩放。终端中捏合缩放到相同预设并保持。设置是每台设备的，不改变桌面终端。
- **自动完成 & 自动纠正** —— 默认关闭，因此 OS 从不重写命令栏中的命令、标志或路径。为手机风格的输入打开它；实时键盘捕获输入仍流式传输原始按键。

## 故障排查

### 防火墙和 Orca Relay

对于 Orca Relay 和登录，允许从桌面和手机到这些主机的出站 TCP 端口 `443`：

| 主机                                                                             | 用途                                       | 协议                          |
| -------------------------------------------------------------------------------- | --------------------------------------------- | --------------------------------- |
| `login.onorca.dev`                                                               | Orca 登录和 Relay 凭据            | HTTPS                             |
| `auth.onorca.dev`                                                                | 托管登录页面                          | HTTPS                             |
| `relay.onorca.dev`                                                               | Relay 指挥，分配区域单元格 | HTTPS 和安全 WebSockets (WSS) |
| `*.relay.onorca.dev`, including `c1.relay.onorca.dev` and `c27.relay.onorca.dev` | 区域 Relay 单元格                          | HTTPS 和安全 WebSockets (WSS) |

允许到 `relay.onorca.dev` 和 Relay 单元格的 WebSocket 升级和长寿命连接。单元格分配可以改变，因此也允许单元格主机名模式和指挥。Relay 使用出站连接；它不需要入站端口或路由器端口转发。

对于直接 LAN 或 Tailscale 连接，改为允许已配对桌面的监听端口。默认是 `6768`，但使用另一端口的桌面需要该端口被允许。**设置 → 故障排查** 在其防火墙建议中显示已配对端点的端口。

### 常见问题

- **工作树上的卡住旋转动画** —— 手机从桌面代理进程追踪心跳。如果桌面说空闲但手机显示正在工作，强制刷新工作树行同步状态。
- **配对失败** —— Relay 需要桌面登录；仅本地配对需要可达的 LAN 或 Tailscale 端点。如果提供已过期，生成新代码，并检查连接模式和主机地址。
- **认证失败 / 配对无效** —— 桌面不再接受此设备令牌（例如桌面清除了已配对设备后）。首先在横幅上尝试 **重试**（瞬时拒绝可以无需重新配对就恢复）。如果持续失败，从桌面使用 **重新配对**，或 **移除** 主机并再次配对。
- **更新 Orca 移动 / 更新计算机上的 Orca** —— 手机和桌面说版本化的移动协议。如果任一侧太旧，移动会阻止该主机并指向 App Store (iOS)、[GitHub 发布](https://github.com/stablyai/orca/releases) (Android APK 或桌面)，然后返回主机。更新后，刷新连接；如果消息仍然存在，移除主机并再次配对。
- **聊天标签说更新移动** —— 会话在桌面聊天 UI 中启动，此手机的应用太旧无法显示它（标签打开到空面板）。更新移动应用，然后重新连接主机以便它看到新应用。如果应用已是最新且标签在重新连接后仍说更新移动，请报告您的移动应用版本和桌面 Orca 版本。
- **快速命令不可用** —— 更新已配对的桌面，使其通告快速命令能力。
- **无法到达桌面** —— 手机和桌面必须共享网络路径（LAN、Tailscale 或您使用的配对路径）。关闭桌面应用会断开连接；重新打开桌面后手机自动重新连接。
