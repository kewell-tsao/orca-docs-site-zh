---
title: Diff 查看器
---

Orca 的 Diff 查看器专为认真审阅 AI 生成的代码而设计 — 不是匆匆一瞥。每个工作树都有内置的、相对于其起始 ref 的差异对比。

## 功能

- **合并 diff** — 跨越所有已暂存、未暂存和未跟踪文件的差异。
- **行号** — 两侧都有，可切换。
- **图像 diff** — 并排、滑动和洋葱皮模式，适用于二进制图像。
- **HTML 预览** — 在 **查看全部** / 合并 diff 中，工作树中仍然存在的 HTML 区域会显示 **侧边打开预览**（眼睛）按钮，以及始终可见的打开文件控件。预览会在侧边浏览器分屏中打开工作树中的 HTML。已删除的 HTML 和仅提交的合并视图会跳过眼睛图标。
- **合并冲突 UI** — 三方视图和内联解决。
- **文件暂存** — 从源代码控制面板操作。

## 范围

默认情况下，diff 显示相对于工作树起始 ref 的变更。你可以从 diff 工具栏切换为与任何提交、分支或基础引用进行比较。

## 自动换行

当 diff 自动换行开启时，长行会在原位换行，这样宽 diff 可以从上到下阅读而无需水平滚动。默认关闭。在 diff 编辑器标题栏的 **⋯** 操作菜单中切换 **自动换行**，或在 **设置 → 常规 → Diff 自动换行** 下设置全局默认。两个控件共享同一设置 — 在编辑器中切换会全局翻转。

## 文件树

合并 diff 可以在差异块旁显示可折叠的文件树。拖动树的调整大小手柄（或在手柄上使用方向键；Shift 会加倍步长）设置宽度 — 大小会跨会话记住。从合并 diff 工具栏折叠或显示该树。

## 键盘快捷键

- `F7` / `Shift+F7` — 在活动编辑器中下一处 / 上一处更改。
