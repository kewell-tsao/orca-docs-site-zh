## 标签

每个标签容纳一件事：终端、编辑器缓冲区、浏览器、差异、PR。标签位于 **标签组** 内。

- 在组内上下拖动标签重新排序。
- 将标签拖到另一个组上移动它。
- 在活动工作树中用 macOS 上的 `Cmd+Option+W` 或 Windows / Linux 上的 `Ctrl+Alt+W` 关闭所有编辑器文件标签。
- 活动标签的颜色条标记哪个面板获得焦点。

### 切换标签

**新安装**的默认和弦：

| 操作                          | macOS                           | Linux / Windows                 |
| ------------------------------- | ------------------------------- | ------------------------------- |
| 下一个 / 上一个标签（所有类型） | `Cmd+Shift+]` / `Cmd+Shift+[`   | `Ctrl+Shift+]` / `Ctrl+Shift+[` |
| 下一个 / 上一个标签（相同类型） | `Cmd+Option+]` / `Cmd+Option+[` | `Ctrl+Alt+]` / `Ctrl+Alt+[`     |
| 上一个最近的标签             | `Ctrl+Tab`                      | `Ctrl+Tab`                      |

可在 [设置 → 快捷键](/docs/settings) 下重新映射。现有安装将自定义覆盖保留在 `~/.orca/keybindings.json` 中。

## 分屏面板

将标签拖到面板边缘创建分屏：

- **右边缘** —— 左右分割（水平分屏）。
- **底部边缘** —— 上下分割（垂直分屏）。

分屏可以嵌套。您可以同时拥有左边一个代理终端、右上一个差异视图、右下一个浏览器标签 —— 全部在同一时刻。

终端标签也可以在标签内部分屏。使用终端标签菜单进行 **向右分割终端** 或 **向下分割终端**，或使用活动终端面板头部的分割按钮进行向右分割。

## 固定边界

面板边界保持您放置的位置。调整窗口大小不会打乱您的布局；边界位置按工作树保存。

## 跨工作树的标签组

每个工作树拥有自己的标签布局。切换工作树会交换整个面板树 —— 您的浏览器标签、终端和差异会确切地在您离开的位置重新出现。
