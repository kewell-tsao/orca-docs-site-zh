---
title: 文件资源管理器与外部拖放
---

文件资源管理器位于每个工作树的左侧。它实时跟踪你的磁盘文件 — 创建、重命名、删除和移动都映射到文件系统操作，因此外部变更（比如来自代理的）会立即显示。目录列表先按目录排序、再按文件排序，使用**自然（数字感知）名称顺序** — `9`、`99`、`100` 而不是字典序的 `100`、`99`。相同排序也适用于 SSH、远程运行时、源代码控制树节点、文件夹选择器和移动端文件树。

## 外部拖放

- 从 Finder/Explorer 将文件拖到文件树中复制进来。
- 将图像拖到 markdown 编辑器中插入到光标位置。
- 将文件拖到代理终端以在提示符处粘贴其路径。
- 对于 [SSH 工作树](/docs/ssh)，拖放同样可用 — Orca 会在完成拖放前将文件上传到远程主机，因此代理看到的是真实的磁盘路径。

## Git 状态

文件按 git 状态上色 — 未跟踪、已修改、已暂存、已忽略。右键可获得常规操作：丢弃、暂存、重命名、**复制路径** 和 **复制相对路径**（默认 `Cmd+Option+Shift+C` / `Ctrl+Alt+Shift+C`；可重映射）。

右键单个文件并选择 **复制** 会将文件本身放到操作系统剪贴板。对于 SSH 工作树，Orca 先在本地暂存远程文件，然后将该暂存文件引用写入剪贴板；远程文件夹会被排除。

## 下载（SSH / 远程）

在桌面应用上，右键远程文件 → **下载**，或远程文件夹 → **下载文件夹**（当连接支持递归传输时）。Orca 会打开原生保存/文件夹对话框。Web 客户端不可用。本地工作树不显示此操作。

## 搜索文件夹

右键文件夹并选择 **在文件夹中查找** 打开搜索，且搜索范围已经限定为该文件夹。你也可以在文件资源管理器中选择文件夹，然后在 macOS 上按 `Cmd-Shift-F` 或在 Windows 和 Linux 上按 `Ctrl-Shift-F`。
