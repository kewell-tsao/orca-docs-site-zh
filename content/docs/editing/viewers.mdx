Orca 包含内置查看器，用于大多数仓库中出现的格式。

## HTML

使用 **在 Orca 浏览器中打开** 或 **侧边打开预览** 打开本地、SSH 或配对运行时上的 `.html` 文件。Orca 在一个沙盒浏览器标签中本地渲染文档，并通过工作空间的文件连接读取文件及其相对资源，因此远程设计文档保持清晰，而不会暴露你的桌面文件系统。

预览在读取额外文件夹前会询问，并且仅授予你批准的那些文件夹。外部 HTTP(S) 链接需要确认，并在普通 Orca 浏览器标签中打开；文档预览内禁止下载。使用 **预览选项** 从磁盘重新加载、打开源文件，或复制其完整路径或工作空间相对路径。

在配对运行时上，HTML 链接也可以预览未注册工作空间外的文件。Orca 使用服务器每文件的访问授予；无需项目注册或 web 服务器。对于这些文档，预览最初只读取打开的文件，在加载同目录的其他文件前会询问。更新较旧的配对服务器如果无法授予文件权限。非常旧的配对服务器可能在没有二进制资源的情况下渲染文档；如果远程图像无法加载，请更新服务器。

## Mermaid

Mermaid 图表在 markdown 预览内联渲染。独立的 `.mmd` 文件在专用查看器中打开，支持平移/缩放。

## PDF

滚动、缩放和文本选择。适合仓库中检入的设计文档。当你离开 PDF 标签再回来时会恢复滚动位置（包括同会话内的关闭后重新打开）— 页面加上页面内偏移，让你回到离开的位置。位置仅在会话内有效，Orca 重启后清空。

## 图像

`.png`、`.jpg`、`.svg`、`.webp`、`.gif`。图像 diff 模式并排比较同一文件的两个版本。

## CSV / TSV

`.csv` 和 `.tsv` 文件在表格查看器中打开，列可排序且支持快速搜索。适合 fixtures、导出数据和任何检入仓库的表格数据。使用工具栏切换回原始文本视图，如果你需要直接编辑单元格。

## Jupyter notebook

`.ipynb` 文件在 notebook 查看器中打开，带渲染后的 markdown、语法高亮的代码单元格和已保存的输出。编辑单元格会写回磁盘上的 `.ipynb`，同时保留 nbformat，因此 diff 保持干净。
