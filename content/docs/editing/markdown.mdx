---
title: 富文本 Markdown 编辑器
---

Markdown 文件默认在富文本编辑器中打开 — 斜杠菜单、工具栏、图像和代码的内联预览、内部链接自动补全。随时按 `Cmd-Shift-M` 切换到原始 Monaco。

对于大于 300 KB 的文件，Orca 先打开原始编辑器以保持输入响应。当你想让该文件使用富文本编辑器时，在回退横幅中选择 **仍然打开**；该选择会持续到你关闭其标签。使用富文本编辑器无法安全保留的 Markdown 结构的文件仍保留在原始编辑器中。

## 斜杠菜单

在空行上输入 `/` 打开斜杠菜单：标题、列表、代码块、提示、图像、mermaid 图表和切换块。

使用 `/toggle-text` 创建可折叠注释，或 `/toggle-h1` … `/toggle-h5` 让切换摘要的样式像某个级别的标题。你可以就地编辑嵌套切换。Orca 将切换保存为可移植的 `<details>` / `<summary>` markdown，因此文件在 Orca 外仍然能正常预览。

## 内部链接

输入 `[[` 开始一个 wiki 风格的链接。Orca 会在工作树内自动补全文件路径并插入相对链接。

## 搜索

编辑器内 markdown 搜索会考虑渲染后的文本，而不是原始 markdown — 因此搜索"Install"可以找到标题，无论它写的是 `# Install` 还是 `<h1>Install</h1>`。

## 审阅注释

当你在 Orca 的富文本编辑器中审阅 markdown 时，选择渲染后的文本即可添加注释，无需切回原始 markdown。Orca 会将备注绑定到选定的源范围，这样它可以在你继续编辑渲染后的文档时展示评论。

**添加审阅备注** 是一个可重映射的快捷键（默认 `Cmd+Shift+A` / `Ctrl+Shift+A`，在 [设置 → 快捷键](/docs/settings) 中）。

## Front matter

YAML 和 TOML front matter 默认在富文本编辑器和渲染预览中显示，这样 docs 和静态站点文章就能暴露其元数据，而无需切换到原始 markdown。打开编辑器的 **更多操作**（`…`）菜单，在想要纯正文视图时选择 **隐藏 front matter**；同一菜单可以切回 **显示 front matter**。此切换是按文件生效的，因此在一个文档上隐藏不会影响其他文档。

## 表格

在富文本 markdown 表格中：

| 操作                                                             | 行为                                                         |
| ---------------------------------------------------------------- | ------------------------------------------------------------ |
| **Tab** / **Shift-Tab**                                          | 下一个 / 上一个单元格；在最后一个单元格之后按 Tab 插入新行   |
| **Enter**                                                        | 移动到下方的单元格；在最后一行添加一行                       |
| **在完全空行上按 Backspace**                                      | 删除该行（如果是最后一行则删除整个表格）                     |
| **在仍有内容的行中，空单元格内按 Backspace**                     | 退回到上一个单元格                                           |

使用 **Shift-Tab** 取消列表项或代码块中选定行的缩进。

当光标在表格中时，富文本编辑器工具栏会显示一键 **行列插入/删除** 控件。右键点击表格单元格可以在上下文菜单中找到同样的结构命令（Table 子菜单仅在目标是表格单元格时出现）。

## 目录

对于长文档，点击编辑器标题栏中的 **目录** 按钮（树图标）打开固定在编辑器左侧的标题大纲。点击标题跳转过去；折叠和展开控件让深层嵌套章节保持可读。在富文本和预览模式中都可用。

## 作为 artifact 分享

从编辑器标题栏使用 **作为 artifact 分享** 将打开的 Markdown 文件发布为公开查看链接，通过你已登录的 Orca 账户。需要开启 **设置 → Artifacts → 允许发布公开 artifact 链接**（新 profile 默认开启）。当 Orca 仍保留映射时，重新发布会更新同一个链接；从侧边栏 **Artifacts** 页面管理或删除链接。代理和脚本可以使用 `orca artifacts share|update|list|delete` — 参见 [CLI 参考 → Artifacts](/docs/cli/reference#artifacts)。
