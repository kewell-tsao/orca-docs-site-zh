---
title: Monaco 编辑器与自动保存
---

Orca 的代码编辑器是 Monaco — VS Code 使用的同一个编辑器 — 带有一些 Orca 特定的调整。

## 自动保存

文件在失焦后和短暂空闲后保存。没有"脏"点，因为在正常流程中不会有未保存的变更。

## 末尾换行

在 [设置 → 常规 → 编辑器](/docs/settings) 下启用 **插入末尾换行**，以在从代码编辑器保存非空文件时添加缺失的换行符。默认关闭，保持文件的 LF 或 CRLF 行尾，且不移动光标。富文本 Markdown、笔记本和 CSV 编辑器不受影响。

## 行尾

新文件和还没有换行的文件使用运行文件工作空间的系统的行尾：Linux 和 macOS 主机、WSL 主机、以及在 WSL 中运行的 Windows 项目使用 LF；其他 Windows 环境使用 CRLF。在 [设置 → 常规 → 编辑器](/docs/settings) 下的 **行尾** 中选择 LF 或 CRLF 以始终使用某一种。该设置仅在文件最多只有一行时才生效。一旦文件有了换行，Orca 就绝不会改变它们，因此你输入的行会保持自己的行尾。已经有换行而打开的文件，或从编辑器外部写入文本获得换行的文件，即使你清空它也会保持自己的行尾。当来自外部带换行的文本写入一个最多只有一行的文件时，文件会采用该文本的行尾。如果你在远程 SSH 主机或 Orca 服务器报告其系统之前输入了多行，那些行会保持编辑器启动时的行尾。WSL 主机从一开始就被视为 Linux，因此不受影响。shell 脚本始终以 LF 开头。

## 多光标、跳转定义、查找

- `Cmd-D` — 选中下一处出现。
- `Cmd-F` / `Cmd-Shift-F` — 文件内查找 / 工作树查找。文件内查找在有选中文本时会用当前选择预置搜索框。
- `Cmd-Click` — 跳转定义（在语言扩展支持的地方）。

## 变更视图模式

在任何编辑器标签中切换 **变更视图模式**，将文件变成标签内的 HEAD 对比工作树 diff，而不离开你的光标位置。再次切换返回常规文件视图。

## 自动换行

文件编辑器默认会自动换行长行。从编辑器标签的 **⋯** 菜单切换 **自动换行**、按 `Alt+Z`（与 VS Code 相同；可在 [设置 → 快捷键](/docs/settings) 中重映射），或在 [设置 → 常规 → 编辑器自动换行](/docs/settings) 下设置默认值。此设置与 **Diff 自动换行** 分开，后者仅影响 diff 编辑器。

## Minimap

在 [设置 → 外观](/docs/settings) 下，文件编辑器中有可选的 Minimap。默认关闭；如果你更喜欢 VS Code 风格的概览栏，可以开启。

## 自定义编辑器字体

默认情况下，编辑器和 diff 视图使用与终端相同的字体。将 [设置 → 外观](/docs/settings) 下的 **编辑器字体族** 留空以保持这种关联；设置字体则只覆盖编辑器（UI 字体保持独立）。

## 语言支持

Monaco 开箱即用支持的语言都内置语法高亮。Orca 刻意偏编辑器优先，而非 IDE 优先 — 请在终端面板中运行类型检查器和 linter。
