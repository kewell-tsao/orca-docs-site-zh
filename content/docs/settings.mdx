设置按面板分组。所有内容都可以用 `Cmd-,` 然后键入关键字搜索。这些文档中的功能页面直接链接到相关面板。

## 通用

- **Orca CLI** —— 注册附带的命令行工具，供 shell 和代理使用。
- **更新** —— 检查和安装更新。**检查更新** 的修饰键点击：

| 修饰键                                               | 效果                                                                                                                                         |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **Shift+click**                                        | 包含最新 **RC** 预发布                                                                                                           |
| **Cmd+click** (macOS) / **Ctrl+click** (Windows/Linux) | 最新 **perf** 标签的预发布                                                                                                              |
| **Option+click** (仅 macOS)                          | 选择 **已验证的本地 macOS 构建**（兼容性已检查）。失败显示为"无法使用本地构建"并带有 **选择另一个构建**。 |

- **在菜单中打开** —— 在工作树 **在菜单中打开** 中选择应用。VS Code / Insiders 为 SSH 工作树启用 **远程 SSH** 打开；其他编辑器保持仅本地路径。
- **UI 缩放** —— 每个安装的 UI 比例。
- **默认新工作树名称** —— 自定义前缀或海洋生物。
- **编辑器自动换行** —— 文件编辑器的默认换行（默认开启）。从文件标签的 **⋯** 菜单或 `Alt+Z` 切换。与 **差异自动换行** 分开。
- **插入最终换行符** —— 从代码编辑器保存非空文件时添加缺失的换行；默认关闭。
- **行尾** —— 新文件和尚无换行的文件的行尾：自动（遵循运行文件工作空间的系统：Linux、macOS 和 WSL 为 LF，Windows 为 CRLF）、LF 或 CRLF。有换行的文件保持其自身设置。

## 外观

- 主题、强调色、密度。
- UI 字体；编辑器字体可选（空值 = 跟随终端字体；设置值仅覆盖文件编辑器和差异）。
- 编辑器小地图切换。
- 状态栏切换，包括 **资源管理器**（CPU/内存/会话、守护进程控制、工作空间磁盘扫描）。
- **使用百分比** —— 在状态栏名单上将提供商限制显示为 **已使用 %** 或 **剩余 %**。
- 应用图标 —— 在 Dock 和窗口切换器显示的图标在经典、水彩和蓝色之间循环。
- **语言** —— 主要界面控制。在系统（跟随 OS）、英语、中文（简体）、繁體中文（台灣）、한국어、日本語、Español、Français、Português (Brasil)、Русский、Türkçe 或 Deutsch 之间切换。设置搜索还匹配"语言"的原生词（语言 / 語言 / 언어 / 言語 / Idioma / Langue / Язык / Dil / Sprache），因此即使 UI 仍为英语您也能找到语言设置。

## Git

- 默认基础引用解析器。
- 提交签名选项。
- 外部 git 工具的编辑器。
- 从工作自动重命名分支 —— 代理开始工作后重命名 Orca 生成的生物分支。
- **GitHub API 预算** —— 来自本地 `gh` CLI 的剩余 REST (core)、搜索和 GraphQL 配额。当 PR 检查或任务停止刷新时很有用；如果数字看起来正常但 GitHub 仍限制实时调用，请参见 [故障排查 GitHub 错误](/docs/github-errors)。

## 终端

- 字体、主题、光标样式、内边距。
- Ghostty 导入。
- Warp 主题导入 —— 使用 **从 Warp 导入主题**（自动按 OS 发现 Warp 的主题文件夹）或 **从 YAML 导入** 导入您的 Warp YAML 主题，用于任何 Warp 格式主题文件文件夹。
- macOS 日语键盘的 JIS Yen (¥) 转反斜杠 (\\)。
- **终端 shell**（本地 macOS / Linux）—— 系统 shell 或自定义可执行文件，默认登录启动。**自定义 shell → 高级 → 自定义参数** 为普通本地面板请求替换参数。参见 [启动文件和参数限制](/docs/terminal#macos-and-linux-shell)。
- Windows 默认 shell（PowerShell 或 CMD）。
- **允许 TUI 剪贴板写入 (OSC 52)** —— **默认开启**。允许 Zellij、tmux、Neovim、fzf、Grok（以及类似工具）通过 PTY 写入系统剪贴板，包括通过 SSH。如果您更喜欢旧的锁定行为则关闭。

## 快速命令

- 保存的终端命令和代理提示预设，全局或项目作用域。每行有命令主体的复制控件。
- 用于评审和编辑命令列表的作用域筛选器。相同列表同步到 [移动伴侣](/docs/mobile)。
- 使用远程或多主机设置时，命令按拥有它们的 Orca 主机分组（**保存在**）。主机所有权与全局/项目作用域以及命令运行位置分开 —— 参见 [终端 → 快速命令](/docs/terminal#quick-commands)。

## 代理

- 已安装的代理 —— 检测到的 CLI，您可以启用或禁用。
- 启用或禁用检测到的代理，启动菜单仅显示您想使用的 CLI。
- 代理权限 —— 为更少的 CLI 权限提示选择 **Yolo**，或为您未自定义的代理保持每个代理自己的批准流程选择 **手动**。
- 每个代理的启动钩子。
- **代理状态钩子** —— 在 Orca 中显示正在工作 / 等待 / 已完成状态。切换无需重启应用（包括 Windows WSL 钩子中继）。CLI：`orca agent hooks on|off|status`。
- **保持电脑唤醒** —— **开启**（持续保持唤醒）、**代理**（代理工作时保持唤醒）或 **关闭**。相同控件在桌面状态栏上为 **咖啡因**（咖啡图标）。在已配对的 Web 客户端中隐藏。
- **技能新鲜度** —— 代理面板和技能卡片仍显示完整状态。侧边栏导航仅徽章需要操作的技能（**有更新可用**、**需要注意** / 评审）；健康、加载和可选未安装的行保持安静。在对话框中使用 **更新** 在后台刷新全局技能（无终端）。进度显示在状态栏；关闭对话框不会取消运行。参见 [Orca 技能](/docs/cli/skills#keep-skills-up-to-date)。

## AI 提供商账户

- 每个提供商的可选已保存账户。没有任何账户时，Orca 使用您现有的登录。
- **Claude** 和 **Codex** —— **添加账户** 登录单独的隔离账户；切换应用于新会话。参见 [热切换 Codex 账户](/docs/agents/codex-hot-swap)。
- **Antigravity** —— **保存当前账户** 记住当前 `agy` 登录，**选择** 将机器共享的 `agy` 登录切换回它。这是切换，不是并行账户。Antigravity 聊天使用自己的登录。参见 [Antigravity 账户](/docs/agents/antigravity-accounts)。

## 聊天

- 选择代理是否在 **设置 → 代理** 中为此电脑作为聊天打开（[远程 Orca 服务器](/docs/remote-servers) 的设置页面不提供此选项）。**将代理作为** 设置默认为 **聊天** 或 **终端**；新安装默认为终端。**已安装** 列表中每个支持的代理行有自己的 **聊天 | CLI** 选择。没有自己选择的代理遵循默认值。
- 现有用户保持其之前的启动选择。现有会话保持其形式。关于在聊天或终端中继续会话，参见 [聊天 UI](/docs/agents/native-chat)。

## 浏览器

- 配置文件（参见 [浏览器使用配置文件](/docs/browser/profiles)）。
- 默认缩放 —— 应用于新打开的浏览器标签的缩放级别（每个标签通过 Cmd 滚轮的调整单独记住）。
- 设计模式默认值。
- Devtools 选择加入。
- **远程服务器工作空间** —— 选择 **此设备** 在桌面上渲染新的配对运行时浏览器页面，或 **服务器（流式传输）** 在服务器上渲染。流量始终通过远程服务器，此选择仅应用于新页面。参见 [每个工作树的浏览器 → 远程工作空间](/docs/browser/overview#remote-workspaces)。
- **通过 SSH 工作空间主机浏览** —— 通过每个工作空间的 SSH 主机发送浏览器流量和 DNS。关闭改为从此设备浏览。
- **链接路由** —— 在 Orca 的浏览器或系统浏览器中打开终端、Markdown 和编辑器中的 http(s) 链接。嵌套的 **按住 Shift…** 为一次点击反转该默认值（`⇧⌘-click` / `Shift+Ctrl+click`）。参见 [每个工作树的浏览器](/docs/browser/overview#link-routing)。
- **显示终端链接操作** —— **默认开启**。终端链接上的普通点击打开紧凑操作弹出窗口。关闭改为需要 `⌘`-click / `Ctrl`-click。参见 [终端 → 链接操作](/docs/terminal#link-actions)。
- **默认搜索引擎** —— 在浏览器地址栏或 [新标签全能框](/docs/model/quick-open#new-tab-omnibox) 中键入非 URL 文本时使用。

## 制品

- **Orca 账户** —— 登录（与 Orca Relay 同一账户体系）以发布和管理共享文件。
- **允许发布公共制品链接** —— **对新配置文件默认开启**；在此默认值之前创建的配置文件保留其之前的设置。设备级门控：开启时，您、代理和此机器上的 `orca` CLI 可以上传 HTML/Markdown 并生成公共查看链接。关闭不会删除现有链接。
- **显示制品** / 侧边栏快捷方式 —— 打开制品列表以搜索、预览、复制或删除账户拥有的链接。
- **删除制品前询问** —— 断开公共链接前的可选确认。
- 从打开的本地 HTML 页面或 Markdown 编辑器使用 **作为制品共享** 共享，或通过 `orca artifacts …`。参见 [CLI 参考 → 制品](/docs/cli/reference#artifacts)。

## 集成

- GitHub —— 使用运行 Orca 的机器上的 `gh` CLI 登录（在 [远程 Orca 服务器](/docs/remote-servers) 上，在服务器上运行 `gh auth login`）；没有 Orca OAuth 应用需要批准或撤销。期望 `repo`、`read:org` 和 `project` 作用域。参见 [故障排查 GitHub 错误](/docs/github-errors)。
- Linear API 令牌。
- Jira —— Cloud（邮箱 + API 令牌）或自托管 Server/Data Center（PAT 或用户名/密码）。参见 [Jira 项抽屉](/docs/review/jira)。
- Bitbucket Cloud —— 用 **邮箱 & API 令牌**（默认）或 **访问令牌** 连接。Orca 在保存前验证凭据。`ORCA_BITBUCKET_*` 环境变量优先并隐藏连接 / 断开。已保存的凭据留在这台机器上 —— 在 [远程 Orca 服务器](/docs/remote-servers) 上改为在服务器上设置环境变量。参见 [托管评审](/docs/review/github)。
- MiniMax —— 粘贴 MiniMax 会话 cookie（来自 `platform.minimax.io/console/usage`）以启用 MiniMax CLI 的本地使用和速率限制追踪。可选的组 ID 和使用模型字段覆盖从 cookie 中选择的默认值。
- MCP 服务器。

- 代理完成：系统、声音、标签。
- 每个类别的自定义桌面通知声音。
- PR 检查失败。
- 有更新可用。

## 语音

- **启用语音听写** —— 需要麦克风权限（macOS 可能打开隐私与安全）。
- **麦克风** —— 选择听写使用的输入设备。默认为系统麦克风；当您不想要 OS 默认值时选择特定设备（例如耳机）。如果选定的麦克风被拔出或缺失，Orca 回退到系统默认值并显示非阻塞通知。
- **听写模式** —— **切换**（按快捷键开始/停止）或 **按住**（按住快捷键说话）。
- **语音模型** —— 下载/选择设备上模型，或粘贴 API 密钥后使用云端 OpenAI 模型：
  - **Parakeet TDT v3**（推荐）—— 多语言欧洲语言，离线。
  - **Parakeet TDT v2** —— 英语，更快。
  - **Zipformer** 系列 —— 中英双语流式；流式英文/中文；**Zipformer Streaming KO**（韩语）。
  - **Paraformer Bilingual** —— 中文方言 + 英语。
  - **Parakeet TDT-CTC JA** —— 日语。
  - **SenseVoice** —— 中文 / 英语 / 日语 / 韩语 / 粤语，带自动语言检测。
  - **Whisper Tiny** —— 90+ 语言，较低准确度。
  - **GPT Transcribe** —— 云端；需要同一面板下的 OpenAI 密钥。已保存的 GPT-4o mini 或 GPT-4o Transcribe 选择切换到它，因为 OpenAI 在 2027-02-26 关闭它们。
- 监听时，**监听…** 胶囊显示 **停止** 控件；在切换模式下，提示还显示听写快捷键。

## SSH

- SSH 工作树、目标、密码短语、默认身份文件。
- 高级：代理 / 跳转主机；**重用 SSH 连接以加快初始化**（系统 OpenSSH 多路复用；默认开启）。
- Kerberos 主机：来自 OpenSSH 配置的 `GSSAPIAuthentication` 驱动系统 OpenSSH 认证（参见 [SSH 工作树](/docs/ssh)）。

## 远程 Orca 服务器

- 配对和连接到远程 Orca 运行时。
- 将此桌面应用通告为服务器并创建可撤销的访问链接。
- 服务器路由项目、终端和提供商检查的高级默认运行时选择。

## 快捷键

- 完整按键映射 —— 每个绑定可重新映射。
- 切换休眠工作空间默认未绑定；如果您想要侧边栏休眠工作树筛选器的直接快捷键，在这里分配。
- **切换子工作空间** 默认未绑定；分配它以显示或隐藏父工作树的嵌套子项，与点击其 **N 个子项** 标签相同。它作用于悬停的工作树，或未悬停时的活动工作树。
- **切换工作空间看板** 默认未绑定；分配它用一个快捷键打开或关闭工作空间看板。`workspace.openBoard` 的现有绑定继续工作。
- 关闭所有编辑器标签在 macOS 上默认为 `Cmd+Option+W`，在 Windows / Linux 上为 `Ctrl+Alt+W`。
- **标签导航默认值（新安装）：** 下一个/上一个标签 **跨所有类型** 是 `Cmd+Shift+]` / `Cmd+Shift+[`（Linux/Windows 上 Ctrl）。相同类型的下一个/上一个是 `Cmd+Option+]` / `Cmd+Option+[`。上一个最近的标签是 `Ctrl+Tab`。现有安装将自定义覆盖保留在 `~/.orca/keybindings.json` 中。
- **在聊天 UI 和终端之间切换** 在 macOS 上默认为 `Cmd+Shift+J`，在 Windows / Linux 上为 `Ctrl+Shift+F11`，在支持的代理标签中。在这里重新映射或移除其绑定。现有自定义快捷键保留其和弦。在 Windows / Linux 上，当 **切换工作树** 不使用时 `Ctrl+Shift+J` 也会切换，或在终端优先策略下从终端输入切换。
- **添加评审注释** 在 macOS 上默认为 `Cmd+Shift+A` (macOS) / `Ctrl+Shift+A` (Windows / Linux)；可重新映射。
- **发送评审注释给代理** 默认未绑定；分配它以在不使用鼠标的情况下为活动工作树的差异注释打开发送注释菜单。
- **删除工作空间** 在 macOS 上默认为 `Cmd+Shift+Backspace`，在 Windows / Linux 上为 `Ctrl+Shift+Backspace`。悬停您要删除的侧边栏工作空间；Orca 仍会要求确认。

## 仓库

- 每个仓库的基础引用和钩子。
- 工作树创建时自动运行命令。
- 侧边栏的仓库图标：选择图标、完整可搜索表情选择器、上传的图像、网站 favicon 或 GitHub 头像，然后选择预设或自定义十六进制徽章颜色。
- 源代码控制 AI 对提交消息、pull request 详情和分支名称的覆盖。
- **工作树共享路径** —— 从主检出实体化到每个新工作树的 gitignore 路径（macOS 上可用时 APFS 克隆复制，否则符号链接）。补充仓库内提交的 `orca.yaml` 中的 `worktree.sharedDirectories` 和 `.worktreeinclude`（参见 [工作树](/docs/model/worktrees)）。

## 浮动工作空间

- **启用浮动工作空间** —— 全局终端、浏览器和 Markdown 标签表面，**不**绑定到仓库工作树。
- **终端目录** —— 新浮动终端标签的起始目录（`~` = 主目录）。
- **切换按钮位置** —— 浮动工作空间切换出现的位置；键盘快捷键无论按钮位置如何都工作。

## 插件 (Alpha)

- **插件系统** —— 设置 → 插件。打开系统，然后逐个评审并启用每个插件。在您同意之前什么都不会运行。
- **市场** —— 添加 git 市场源，浏览插件，预览能力（面板、命令、语言包、VM recipe），安装、更新或回滚。
- 插件 worker 始终在此计算机上运行；SSH 工作空间操作仍路由通过 Orca。
- 能力和 API 形状可能更改；将第三方插件视为不受信任的软件。

## 实验性功能

- [活动页面](/docs/activity) —— 代理事件的 Slack 风格工作树 feed。
- 紧凑工作树卡片 —— 当布局仍为实验性时隐藏侧边栏中冗余的第二行。
- [代理休眠](/docs/agents/hibernation) —— 暂停空闲后台代理并在重新打开时自动恢复。
- **代理仪表板** —— 需要您 / 正在工作 / 已完成代理（可选空闲）的看板，带有搜索和项目/工作空间/PR 筛选器；在窗口内或作为弹出面板打开。**显示空闲代理** 位于仪表板看板设置控件上，不在这里。参见 [代理 & 会话](/docs/model/agents-sessions#agent-dashboard)。
- **Cloud VM** —— 为仓库拥有的按需环境（云沙箱、VM 或本地 Docker）显示初始化控件和工作空间 **在...上运行** 目标。初始化指南和 recipe 安装在此实验性切换下。参见 [运行 Orca 的方式](/docs/ways-to-run#4-cloud-vms-per-workspace-environments)。
- 尚未稳定的功能 —— 行为可能更改。
