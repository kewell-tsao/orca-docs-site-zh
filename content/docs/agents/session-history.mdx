Orca 扫描受支持的代理 CLI 遗留的磁盘上会话转录，并在一个名为 **代理会话历史** 的右侧边栏面板中列出它们。选择一个过去的会话，点击 **恢复**，Orca 会在新终端中运行代理的恢复命令 — 相同的 `cwd`、相同的会话 ID，无需手动处理 `--resume` 标志。

## 打开面板

打开右侧边栏切换到 **代理** 标签。面板标题写着"代理会话历史"。

标题显示类似 `12 个已展示 · 47 个最近` 的计数，旁边是搜索框。输入内容可以按会话标题、工作目录、分支、模型或对话预览文本过滤。

## 范围

面板顶部的范围开关决定哪些会话会显示：

- **工作空间** — 当前工作空间或工作树中的会话，取决于活跃的工作空间上下文。
- **项目** — 解析到活跃 Orca 项目的会话。
- **全部** — 此机器上所有代理中 Orca 发现的每个会话。

远程工作空间可以浏览本地历史，但恢复操作只在本地工作空间中运行 — Orca 会在活动工作树为远程时在面板中提示这一点。

## 视图选项

搜索框旁边的视图选项菜单控制扫描哪些代理，以及排序和分组：

- **代理** — 切换各个 CLI 的开关（Claude、Codex、Hermes、Pi、OMP、Prime Agent、Cursor、Gemini、Antigravity、Rovo Dev、Copilot、OpenCode、Grok、OpenClaw、Devin、Droid、Kimi、Muse）。被禁用的代理在扫描期间会跳过。使用代理标题栏中的 **全选** / **清除** 一次性翻转所有代理 — **清除** 会全部清空，这样你可以只打开你关心的那个 CLI 而不用一个个取消勾选。空选择时会显示 **未选择代理**，而不是通常的空过滤消息。
- **排序** — `最后更新` 或 `创建时间`。
- **分组** — `项目`、`文件夹`（每个 `cwd` 一个标题）或 `代理`（每个 CLI 一个标题）。
- **隐藏空会话** — 去掉没有记录任何消息的会话。

## 恢复会话

点击会话行打开其详情：工作目录、分支、模型、消息数量、**首个提示** 和最近的对话回合。**首个提示** 会在展开详情时从转录中加载未截断的首条用户消息（列表行只保留简短预览用于搜索）。在该卡片上使用 **复制** 将完整请求放到剪贴板上 — 对于复用长提示而不重新打开日志很有用。你也可以把已启用的会话行拖到工作空间来恢复它。从行的操作中你可以：

- **恢复** — 在会话的 `cwd` 中打开新终端，并运行代理的恢复命令（例如 `claude --resume <id>`、`codex resume <id>`、`pi --session <session_file>`、`prime-agent --resume <path>`、`cursor-agent --resume <id>`、`acli rovodev run --restore <id>`）。当原始会话设置过 `CODEX_HOME` 时，Codex 会话也会重新导出它。

Pi 从其 hooks 报告的磁盘会话文件恢复（`--session <path>`），而不是裸会话 id。如果该文件缺失，即使存在会话 id，该行的恢复也不可用。

- **复制恢复命令** — 将同一条 shell 命令复制到剪贴板，供在外部终端中使用。
- **复制会话 ID** / **复制日志路径** — 用于脚本编写或将会话转录附加到 bug 报告。
- **打开日志** / **在文件管理器中显示日志** — 在 Orca 中打开原始转录文件，或在系统文件管理器中跳转至它。
- **打开 cwd** — 将会话的工作目录作为工作空间打开。

<Callout title="恢复需要本地工作空间">
  恢复是在 Orca 渲染所在的机器上运行代理 CLI。如果你连接到远程
  工作空间，请先切回本地工作空间（或使用 **复制恢复命令** 自己在远程运行）再点击
  **恢复**。
</Callout>

## 转录来源

Orca 读取每个代理自己的磁盘会话存储 — Codex 的 `~/.codex/sessions`、Claude 的 `~/.claude` 历史、Cursor 的会话日志、OpenCode 的旧会话文件或 `~/.local/share/opencode/opencode.db`，等等。无需额外启用；只要 CLI 写入转录，下一次扫描后它就会出现在面板中。使用标题栏的 **刷新会话历史** 按钮可按需重新扫描。
