Chat UI 是一个带有转录、编辑器和代理控件的对话视图。你选择以聊天形式打开的受支持代理会在**结构化聊天**中启动新会话，它直接与代理通信，而不是展示终端会话。其他代理和不受支持的执行环境则在终端中打开。

现有的终端聊天使用终端中运行的代理之上的转录视图。这些会保持原有形态；更改代理的 Chat 或 CLI 选择不会转换现有会话。

## 选择聊天还是终端

Chat UI 对所有人可用。受支持的代理继承你的全局聊天或终端默认设置，除非你为某个代理另行选择。全新安装默认为终端：

你也可以在 **设置 → 代理** 中选择每个受支持代理以聊天形式打开：**已安装** 列表中每个代理的行都有一个 **Chat | CLI** 选择。选择 **CLI** 后它的新会话会在终端中打开。其聊天运行在 Orca 下载的程序上的代理（例如 Antigravity），在你展开该行时会显示下载进度和聊天登录入口。

## 在聊天或终端中继续对话

要以另一种形式打开已保存的对话：

1. 在右侧边栏中打开 **代理会话历史**。
2. 打开对话的菜单。
3. 对于受支持的 CLI 对话，选择 **在新聊天中恢复**；对于受支持的聊天对话，选择 **在新终端中恢复**。

两个操作都会打开带有对话副本的新标签；原始内容保持不变。例如，**在新终端中恢复** 会把 Claude 或 Codex 聊天复制到新的 CLI 会话中。这些操作取决于代理、已保存的对话和执行主机；并非每个会话都可用。较旧版本的 Orca 中它们标记为 **在新原生聊天中恢复** 和 **在新 CLI 中恢复**。

你也可以右键点击已打开的代理标签：

- 在结构化聊天标签上，**用终端代理继续** 会用对话副本启动一个新的终端代理。
- 在受支持的终端代理标签上，**在 Chat UI 中继续** 会在新的结构化聊天中打开对话。终端面板标题栏显示同样的操作（以聊天按钮形式）。

这些继续操作也适用于配对的支持对话历史恢复的 **远程 Orca 服务器** 上的对话。聊天及其历史数据保留在该服务器上。没有 Orca 运行时的直接 SSH 工作空间不支持此操作。如果该操作在较旧的服务器上不可用，请同时更新该服务器和客户端。

如果终端代理仍在持有该对话，Orca 会要求你先停止或退出它再从 **代理会话历史** 继续。在 Chat 中继续不会强制终止终端代理。

## 切换现有的终端聊天

结构化聊天标签没有就地的终端视图；请改用上面的 **用终端代理继续**。

终端聊天是运行中的终端代理之上的一个视图，因此切换它不会创建新会话。使用面板标题栏的 **显示终端** 按钮，或标签菜单中的 **用终端代理继续** 返回终端。在受支持的终端面板内右键点击可得到 **在 Chat UI 中继续**，它会把同一个终端会话展示为转录，而不是创建结构化聊天。

你也可以在 **设置 → 快捷键** 中使用 **在 Chat UI 和终端之间切换**（macOS 默认 `Cmd+Shift+J`，Windows/Linux 默认 `Ctrl+Shift+F11`）来切换同一个终端聊天会话。在 Windows/Linux 上，当 **切换工作树** 没有占用 `Ctrl+Shift+J` 时它也可以切换，或在终端优先快捷键策略下从终端输入中切换。

## 编辑器

- 输入消息并发送（或停止正在运行的回合）。当主机支持时可附加文件/图像。当主机能恢复时，未发送的草稿文本和附件会在断开/重连时跟着面板一起保留。在同一会话重连时，已完成的转录也保持在屏幕上，而不是空白等待重新加载完成（桌面和移动共享此保留行为）。
- 输入 `/` 打开斜杠命令和已发现的**技能**（尽可能按代理过滤）。斜杠目录是代理感知的（Claude 命令集 vs Codex 命令集），并与移动端 Chat UI 共享。
- 当代理暴露模型和选项胶囊时使用它们（思考级别、模式、代理特定的会话选项）。**Claude** 模型选择来自**该主机上已安装的 Claude CLI**（不是硬编码列表），因此新模型会在你更新 CLI 后出现。**Codex** 支持直接从胶囊选择模型（发送 `/model <id>`），而裸 `/model` 仍然打开代理选择器。**Grok** 暴露 **模型**（启动时 `-m`，会话中 `/model`）和 **推理 effort**（启动时 `--reasoning-effort`，会话中 `/effort`）；模型列表是从已登录的 Grok CLI（`grok models`）探测的，因此已下架的 id 会从选择器中消失。Effort 选项跟随选定的模型：Grok 4.6 包含 **Extra high**，而 Grok 4.5 停在 **High**。**在代理进程启动前**，编辑器可以显示首次启动时应用的草稿启动选项；会话存活后，仅影响正在运行的回合的胶囊会保持禁用或打标，直到会话就绪。在结构化聊天中，实时值发送到代理会话；在终端聊天中，它们发送到该标签中的 CLI。

## 代理提出的问题

当 Claude 显示 **AskUserQuestion**（或类似的结构化权限/问题卡片）时，Chat UI 应该在转录中渲染该问题卡片，这样你可以从编辑器路径回答它，而不是把它当作折叠的工具调用处理。在卡片上点击 **提交** 确认。这包括在配对的 [远程 Orca 服务器](/docs/remote-servers) / 无头主机上运行的代理 — 不仅限于本地面板。

## 可用性

Chat UI 在桌面上为受支持的本地和远程（配对服务器）代理会话提供。可用的代理和操作取决于执行主机和客户端能力；较旧的配对主机或不受支持的启动方式仍然在终端中打开。[移动端伴侣](/docs/mobile) 为配对会话复用聊天风格的转录模式；上面的桌面菜单步骤描述的是桌面应用。

<Callout title="聊天还是终端">
  聊天展示对话：消息、工具活动、可视化内容和文件链接。终端展示代理打印的所有内容，包括每一行状态。两者都完全受支持，你可以在
  **设置 → 代理** 中为任何代理切换它们。
</Callout>
