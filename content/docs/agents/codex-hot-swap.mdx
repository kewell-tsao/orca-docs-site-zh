---
title: 热切换 Codex 账户
---

运行多个 Codex 账户以最大化 token 配额是常见做法。Orca 让你一次性添加每个账户，然后一键切换活动账户，无需编辑配置。

## 添加账户

1. 打开 [设置 → AI Provider 账户 → Codex](/docs/settings#ai-provider-accounts)。
2. 点击 **添加账户**，在浏览器中完成 Codex 登录。
3. 对每个账户重复此步骤。Orca 添加的每个账户都会保留各自的登录上下文，因此添加一个账户不会让另一个账户登出。

账户是可选的：如果不添加任何账户，Orca 会使用你平时的 Codex 登录（**系统默认**）。

## 切换账户

点击状态栏中的 Codex 标签打开账户切换器，或在设置中选择一个账户。在此之后启动的任何新 Codex 会话都会使用它，已打开的 Codex 聊天会在下一条消息发送前切换（正在运行的回复会先完成）。已经在运行的终端会话会保持其原始账户，直到重启。

## 并排运行多个账户

因为每个添加的账户都有自己隔离的 home，两个 Codex 终端会话可以在不同账户下同时运行：启动一个，切换账户，再启动下一个。每个终端会话会保持其启动时的账户；聊天始终跟随选定的账户。用量仍然计入各账户自己的配额；Orca 不会跨账户合并额度。

## 系统默认

**系统默认** 行是你当前主机 `~/.codex` 下的 Codex 登录。在 Orca 中添加的账户不会重写那个登录；它们在隔离的 home 中运行。当你希望启动行为与 Orca 外部终端中的 `codex` 一致时，请选择系统默认。

## 当配置编辑似乎被忽略时

对于托管的 Codex 账户，Orca 会将你真实 `~/.codex/config.toml` 中的设置镜像到活动运行时 home。如果源文件缺失、为空（例如云同步仍在下载中）或不可读，账户列表会显示一个警告：Codex 会保持**上次成功同步**的设置，直到源文件恢复正常。修复横幅中提示的路径上的文件，然后重启或重新选择账户。

## 规则与注意事项

- 切换不会重新认证；Orca 在选定账户的 home 中启动新会话。
- 现有 Codex 终端进程会保持当前账户，直到重启。聊天会在下一条消息时切换。
- 状态栏中的用量读数跟随当前活动账户。
- 重启标签在重启时保留活动账户。
- 账户属于运行代理的那台机器。在 [远程 Orca 服务器](/docs/remote-servers) 上，请在该服务器上添加账户。

## 其他提供者

- **Claude Code** 账户以相同的方式在 **设置 → AI Provider 账户 → Claude** 下添加，切换会应用到下一个你启动的 Claude。
- **Antigravity** 的工作方式不同：它切换一个共享的 `agy` 登录，而不是运行隔离的账户。参见 [Antigravity 账户](/docs/agents/antigravity-accounts)。
