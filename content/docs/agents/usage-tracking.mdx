---
title: 用量与速率限制追踪
---

Orca 为 Claude Code、Codex、Gemini、OpenCode Go、Kimi Code、MiniMax、Grok、Antigravity、Cursor 和 GLM Coding Plan 获取用量并在状态栏中展示，这样你就能在代理停滞之前知道离速率限制还有多远。

## 展示内容

- 当前账户计划下的用量。
- 5 小时、每日、每周窗口以及 Claude Fable 每周窗口（如适用）的重置倒计时。
- 当你超过限制的 80% 时出现警告标签。

## 工作原理

Orca 通过网络向每个 provider 请求你的用量，使用代理已有的登录凭据，或你在 Orca 设置中添加的密钥或会话 cookie。

### Claude 用量轮询

**设置 → 账户 → Claude → Claude 用量轮询** 默认开启。关闭后 Orca 将停止向 `https://api.anthropic.com/api/oauth/usage` 发出请求，包括手动刷新、账户切换、未激活账户预览，以及来自移动端或 web 客户端的刷新。关闭会取消未处理的用量请求并移除其缓存数据，同时保留实时终端读数。已经发送的请求无法撤回。

轮询关闭时，计量器使用 Claude Code 的 [状态行数据](https://code.claude.com/docs/en/statusline#rate-limit-usage)：五小时和每周百分比以及重置时间。这需要受支持的 Claude Code 版本和 Orca 的状态行 feed。Orca 会保留用户自己的状态行，因此那些会话不会提供此 feed。没有读数时，用量不可用，直到终端会话报告它。特定模型的每周窗口、额度和未激活账户读数需要轮询。

持久化设置为 `claudeOAuthUsageEnabled: false` 可禁用轮询。它应用于运行代理的主机，包括无头 Orca 服务器；请分别配置每台主机。隐藏 Claude 状态栏条目可以独立控制可见性。

启用轮询时，Orca 使用你现有 Claude Code 登录的 token。触发时机包括：

- Orca 窗口启动后变为活动窗口，然后在它保持可见并聚焦时大约每 15 分钟一次。
- 当最后一次检查超过 5 分钟时，将窗口带回前台（失败后会更快重试）。
- 切换活动的 Claude 账户或它运行的运行时。
- 从 **用量** 弹出窗口或刷新所有用量的设置控件刷新用量，或更改 OpenCode Go、MiniMax 或 GLM Coding Plan 的用量凭据或设置。这些会刷新每个 provider，包括 Claude。
- 在状态栏的 Claude 账户切换器中展开账户列表，获取你其他已保存的 Claude 账户。列表在需要登录的账户时默认展开。
- Orca 移动端或 web 客户端连接到该主机或刷新用量，也会获取你其他已保存的 Claude 账户。

## 多账户计费

状态栏始终反映**活动**账户。其他已配置的账户可以在账户切换器中看到各自的用量。

## 用量列表

点击状态栏中的用量段打开 **用量** 弹出窗口。它列出每个受追踪的 provider（图标 · 名称 · 计划 · 最快重置时间 · 每个窗口的进度条），按最紧张的限制排在前面。使用标题栏的刷新控件重新获取用量。

- **详细** — 每个窗口的完整进度条、标签和百分比
- **紧凑** — 每个 provider 只显示最紧张的窗口

在 [设置 → 外观](/docs/settings) 中选择 **已用 %** 或 **剩余 %** 来决定这些数字的显示方式。

没有实时数据的行显示简短状态：**加载用量…**、**未登录**、**用量不可用**、**无用量数据** 或 provider 特定的错误。Claude 和 Codex 行可以下钻到账户切换；**管理账户** 会打开设置。

### 移动端

在伴侣应用中，打开主机的 **账户** 屏幕查看相同的切换器/用量读数。当 Codex 获得了**速率限制重置** 额度时，在该屏幕使用掉一个（参见 [移动端伴侣](/docs/mobile)）。

## 估算费用（统计）

统计明细可能为已知模型家族（包括 Claude 5 系列和 Codex GPT-5.6 行）显示**估算费用**。标记为 **• 推断定价** 的行使用的是 Orca 的本地价格表，而不是来自 provider 的实时账单。请优先使用 provider 控制台获取权威的费用数据。
