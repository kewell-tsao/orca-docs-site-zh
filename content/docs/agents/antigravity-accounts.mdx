---
title: Antigravity 账户
description: 保存多个 agy 登录并在它们之间切换。
---

Orca 可以记住多个 Antigravity CLI (`agy`) 账户并在它们之间切换。与 [Codex](/docs/agents/codex-hot-swap) 不同，这是**切换一个共享的登录**，而不是并排运行隔离的账户。

## 保存账户

1. 在运行代理的机器上的终端中运行 `agy`，完成其浏览器登录。
2. 打开 **设置 → AI Provider 账户 → Antigravity** 并点击 **保存当前账户**。
3. 要添加另一个账户，在 `agy` 内运行 `/logout`，用下一个账户登录，点击 **刷新账户**，然后再次点击 **保存当前账户**。
4. 对每个账户重复此步骤。

## 切换账户

点击已保存账户旁的 **选择**。Orca 会将该登录写入此机器上 `agy` 自己的凭据存储，并检查 `agy` 现在是否报告该账户。新的 `agy` 会话会使用选定账户。已经在运行的会话可能会保持之前的账户，直到重启。

## 并发限制

- `agy` 在每台机器上只保留一个登录，因此该机器上的新 Antigravity 终端都使用当前选定的账户。正在运行的会话可能保持之前的账户，但你无法同时将两个新会话固定到两个不同的账户。
- 保存多个账户不会给你并行隔离的身份，Orca 也不会跨账户合并额度。
- 状态栏中的 Antigravity 用量反映的是当前登录到 `agy` 的账户。选择另一个账户并刷新用量即可查看其配额。

## Antigravity 聊天

[Chat UI](/docs/agents/native-chat) 中的 Antigravity 使用自己独立的登录，与你的 `agy` 账户分开。已保存的 `agy` 账户不会决定聊天使用哪个账户；请在同一设置区域的 **Antigravity** 聊天行中为聊天登录。

## 账户存储位置

- 账户属于运行 `agy` 的那台机器。在 [远程 Orca 服务器](/docs/remote-servers) 上，请在该服务器上保存和选择账户。
- 在 Windows 上，Orca 管理 Windows `agy` 登录，或选定为账户位置的 WSL 发行版内的 `agy` 登录。每个发行版保留各自已保存的账户。管理账户前请先启动发行版；Orca 不会替你启动。
- 在 Linux 桌面上，`agy` 将登录存储在系统密钥环（Secret Service）中。Orca 需要 `secret-tool`（来自 `libsecret-tools` 或你发行版的等价包）和一个已解锁的密钥环来切换。没有会话总线的无头主机、容器和 SSH 会话则改为使用 `agy` 的凭据文件。
