---
title: 终端
---

Orca 的终端与 VS Code 使用的相同 —— 基于 xterm.js，加上一些为 AI 代理工作流调整的添加功能。

## 面板 & 标签

终端只是标签 —— 参见 [标签、面板 & 分屏布局](/docs/model/tabs-panes-splits)。分割终端面板让您并排获得两个 shell。

代理终端标签显示代理身份加上实时状态：正在工作、等待输入、已完成或已完成但未读。对于 Claude 和 Codex，当 Orca 能将面板映射到该会话时，标签标题还可以显示 **AI Vault 会话名称**（自定义标题 / 线程名称）—— 手动重命名优先。

## 资源管理器终端

**资源** 视图在桌面应用和已配对的 Web 客户端中都工作（只要其页面可见）。单独的 **PTYs** 视图管理本地桌面终端；Web 客户端无法结束这些终端。

**刷新** 发现自上次观察以来创建的终端。**结束** 需要主机在停止前能检查选定终端的标识、代理所有权和附件。旧主机、模糊所有权或断开联系无法确立安全的结束结果。

如果因为终端主机缺少支持而 **结束** 不可用，从其终端标签或在其主机上手动结束终端。

确认的 **结束** 会像 **关闭** 一样删除保存的终端历史。如果较新的终端在清理进行中替换了选定的终端，那个较新的终端仍保留在清单中并保留其历史。

## TUI 剪贴板 (OSC 52)

许多终端 UI（Zellij、tmux、Neovim、fzf、Grok）通过 **OSC 52** 而非 OS 剪贴板 API 进行复制。Orca **默认** 允许这些写入，因此通过 SSH 的远程/TUI 复制与本地工作方式相同。

切换：[设置 → 终端 → 允许 TUI 剪贴板写入 (OSC 52)](/docs/settings)。

## 搜索

`Cmd-F` 打开滚动缓冲区内查找。支持匹配高亮、大小写、正则和匹配导航。

## 链接操作

终端链接（HTTP/OSC 8 URL、文件路径、工作空间、终端或任务句柄）上的普通点击会打开紧凑的操作弹出窗口，而不是立即导航。本地 web 链接和由能力验证的已配对运行时拥有的链接提供 **Orca 浏览器** 和 **系统浏览器**；来自旧运行时的链接仅限系统。SSH 链接其主机被路由时遵循 [链接路由](/docs/browser/overview#link-routing)。当主机的 SSH 浏览设置为 **此设备** 时，它们在仅从此设备浏览的 Orca 标签中打开；否则仅限系统浏览器。Web 链接还会获得 **复制链接**，它在不关闭弹出窗口的情况下复制解析后的 URL（包括隐藏的 OSC 8 目标）—— 文件和工作空间目标保持不变。`Cmd`-click (macOS) / `Ctrl`-click (Windows / Linux) 仍然直接打开，`Shift+Cmd` / `Shift+Ctrl`-click 仍使用 [链接路由](/docs/browser/overview#link-routing) 的备用方式。

可预览的 HTML 文件链接可以从本地、SSH 和已配对运行时工作空间在 Orca 中打开；远程文件行还提供 **下载 & 用默认应用打开**。如果链接的文件已在兄弟工作空间标签中打开，Orca 会激活该标签而非打开重复。参见 [HTML 查看器](/docs/editing/viewers#html)。

在 [设置 → 浏览器 → 显示终端链接操作](/docs/settings) 下关闭弹出窗口。关闭后，打开链接需要修饰键点击。

## 复制终端上下文

右键点击终端并选择 **复制上下文** 以从该面板复制有界的转录。当您想要将最近的代理输出粘贴到另一个工具而不启动 Orca fork 时使用它。

## 主题

终端颜色主题可在 [设置 → 终端](/docs/settings) 下配置。Orca 附带流行主题库，允许您自定义其中任何一个。

## Ghostty 导入

如果您使用 Ghostty，Orca 可以在首次启动时导入其主题、字体和光标配置。您可以稍后从 [设置 → 终端 → 从 Ghostty 导入](/docs/settings) 重新运行导入。

## Warp 主题导入

如果您在 Warp 中收集了主题，点击 [设置 → 终端](/docs/settings) 下终端主题选择器中的 **从 Warp 导入主题** 将它们带入作为 Orca 终端主题。Orca 按当前 OS 扫描 Warp 的主题目录（macOS 上 `~/.warp/themes`，Linux 上 `$XDG_DATA_HOME/warp-terminal/themes`，Windows 上 `%APPDATA%\warp\Warp\data\themes`），让您选择要导入的 YAML 主题。旁边的 **从 YAML 导入** 按钮使用相同的选择器指向任何 Warp 格式的 `.yaml`/`.yml` 文件文件夹 —— 当您将主题存储在默认位置之外时很有用。

导入的主题与 Orca 内置主题一起出现在主题下拉菜单中。

## macOS 和 Linux shell

默认情况下，macOS 和 Linux 上的本地终端面板将您的系统 shell (`$SHELL`) 作为 **登录 shell** (`-l`) 打开。使用默认参数：

- **zsh** 从 `$ZDOTDIR` 或您的主目录 (`~`) 按顺序读取 `.zshenv`、`.zprofile`、`.zshrc` 和 `.zlogin`（如果未设置 `$ZDOTDIR`）。每个用户文件遵循其系统对应物（`zshenv`、`zprofile`、`zshrc`、`zlogin`），通常在 `/etc` 或 `/etc/zsh` 下。
- **bash** 先读取 `/etc/profile`，然后是 `~/.bash_profile`、`~/.bash_login` 或 `~/.profile` 中存在的第一个。它 **不** 自行读取 `~/.bashrc`。如果您的 `PATH` 或版本管理器设置（nvm、asdf、mise）位于 `~/.bashrc`，从该登录文件 source 它，就像许多发行版的默认 `~/.profile` 或 `~/.bash_profile` 已经做的那样：

  ```bash
  [ -n "${BASH_VERSION:-}" ] && [ -f "$HOME/.bashrc" ] && . "$HOME/.bashrc"
  ```

  这个保护让也读取 `~/.profile` 的非 bash shell 不会加载仅 bash 的设置，即使启用了 `set -u`。仅当 bash 读取的登录文件尚未 source `~/.bashrc` 时才添加它。

当 Orca 使用其 bash 集成包装器时，它用 `--rcfile` 而非 `-l` 启动 bash。包装器 source 相同的登录文件而不单独 source `~/.bashrc`；bash 本身不在登录模式。

要打开不同的 shell，在 [设置 → 终端 → 终端 shell](/docs/settings) 下选择 **自定义 shell**。在 **高级 → 自定义参数** 下，每行输入一个参数以替换普通本地面板的默认 `-l`。空列表表示无参数：未包装的交互式 bash 然后读取 `~/.bashrc` 而非登录文件。当终端守护进程不可用时，Orca 的 bash 或 zsh 集成可以覆盖自定义参数并保留登录启动。代理启动、启动命令和一次性 shell 选择不使用此参数设置。

## Windows shell

Windows 上的默认 shell 可在 [设置 → 终端](/docs/settings) 下在 PowerShell、命令提示符和 WSL 之间配置。当 `wsl.exe --status` 成功时自动提供 WSL。标签条上的 **+** 下拉菜单也显示子菜单，因此您可以在不更改默认值的情况下在任何 shell 中打开一次性标签。

对于 WSL 文件系统上的仓库（`\\wsl.localhost\...`），Orca 通过 `wsl.exe -d <distro>` 启动。对于在 WSL 中打开的 Windows 路径仓库，Orca 将 cwd 转换为 `/mnt/<drive>/...` 并让您进入登录 bash。

## Windows 管理员模式

打开 **设置 → 终端 → 管理员模式** 查看 Orca 应用是以 **管理员** 还是 **标准用户** 运行。**无法确定** 意味着 Orca 无法读取其 Windows 提升状态。现有终端可以有与应用不同的权限。

在已安装的 Windows 应用中，选择 **以管理员身份重启**，评审确认，然后使用您通常的账户批准 Windows 提示。批准后，Orca 替换其当前的本地终端主机。这会结束该主机的终端和正在运行的代理；恢复的终端标签打开新的管理员 shell。SSH 和 WSL 权限继续在其主机上控制。保留在旧主机上的终端保持其原始权限。

如果您取消 Windows 提示或提升失败，Orca 会以其之前的权限重新打开并保留其终端会话。

手动启动时，完成您的本地终端工作并退出 Orca。在 Windows 开始菜单中找到 Orca，右键点击它，选择 **以管理员身份运行**。如果新终端仍有普通权限，使用 **设置 → 终端 → 管理会话 → 重启守护进程**。这会结束当前本地主机上的终端；新打开的本地 shell 继承管理员应用的权限。设置的手动说明包含管理会话的直接链接。

要检查 PowerShell 终端自身的权限，运行：

```powershell
([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)
```

`True` 意味着该 PowerShell 进程具有管理员权限。

管理员模式应用于整个应用。在外部 PowerShell 窗口中运行 `orca` 命令时，以与 Orca 相同的管理员模式运行该窗口。

要返回普通权限，完成并关闭所有本地终端会话，退出 Orca，正常启动它。关闭会话让保留的终端主机在 Orca 断开连接后可以退役；让会话继续运行即使在应用退出后也可能保留管理员主机。管理员状态提供带有这些步骤的 **标准模式指南**。

## 快捷键

- `Cmd-T` —— 当前工作树中的新终端标签。
- `Cmd-Alt-T` (macOS) —— 使用您默认代理的新代理标签。在 Linux 和 Windows 上此和弦未绑定；在 [设置 → 快捷键](/docs/settings) 下分配一个（搜索"新代理标签"）。每个支持的代理也有自己的"新代理标签"操作 —— 绑定和弦以直接启动特定 CLI 而不经过默认设置。
- `Cmd-W` —— 关闭当前标签。
- `Cmd-\` —— 向右分割。
- `Cmd-Shift-\` —— 向下分割。

## 原生按键绑定

Orca 通告 kitty 键盘协议，因此终端应用能看到真正的 `Shift+Enter`、`Ctrl+Enter` 和其他修饰键感知的按键 —— 绑定在 Orca 中的工作方式与 Ghostty、WezTerm 或您的原生终端相同。

对于 macOS 上的日语 JIS 键盘，如果您希望物理 Yen 键在终端会话中发送反斜杠，请启用 **设置 → 终端 → JIS Yen (¥) 转反斜杠 (\\)**。

## 浮动终端

浮动终端是一个全局 shell 表面，无论您在哪个工作树或标签上，都始终距离一个和弦之遥。对新安装默认开启。

- 用 `Cmd+Option+A` (macOS) / `Ctrl+Alt+A` (Linux/Windows) 切换。如果面板已打开则聚焦它，如果已聚焦则关闭它。
- 点击窗口边缘的浮动按钮，或在 [设置 → 终端 → 浮动终端](/docs/settings) 下将触发器移动到状态栏。
- 在同一设置下设置起始工作目录（默认 `~`），以便新浮动标签落在您期望的位置。
- 浮动面板有自己的标签，支持编排初始化 —— 无需占用工作树面板即可启动后台运行。

## 快速命令

快速命令保存您经常运行的终端命令，例如 `npm run dev`、`pnpm test` 或项目特定的初始化脚本。它们还可以为 Claude 和 Codex 等启动时提示代理保存可重用的代理提示。从 **设置 → 快速命令** 或标签条的 **添加命令** 按钮创建它们，然后从工作树标签条的快速命令分割按钮或终端上下文菜单运行它们。

每个命令有一个标签、命令文本和作用域。为适用于任何地方的命令使用 **全局**，或为仅在特定仓库的工作树中显示的命令使用 **项目**。标签条按钮打开新终端标签并运行命令；终端上下文菜单可以将命令插入当前终端。使用命令行的复制控件（设置列表、标签条菜单或 [移动快速命令](/docs/mobile#quick-commands)）将命令主体放在剪贴板上。

当您使用已配对的 [远程 Orca 服务器](/docs/remote-servers)（或另一个执行主机）时，选择器可以并排显示 **本地和远程** 集合，按主机标记（例如 _本地 Mac_ 和 _Orca 服务器_）。**保存在** 是命令存储的位置；运行命令仍然在您调用它的终端或工作空间中执行 —— 因此客户端拥有的命令可以在远程工作树内运行。不通告多主机快速命令的旧服务器回退到仅本地列表。
